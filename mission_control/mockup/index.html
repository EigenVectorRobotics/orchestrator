def run(skills, places):
    pose = skills.read_pose()
    near = min(places, key=lambda p: p.distance(pose))
    skills.say(text=f"I am near {near.name}")
    return {"place": near.name}

Feature sets

What each part of Mission Control shows or does, and the ROS interface behind it. An adapter node on the NUC collects the state and serves this page on 127.0.0.1:8080; the laptop opens it through ssh -L 8080:localhost:8080. Commands go through the same topics as agent_cli, so the step gate, the limits and the recorder see no difference.
