# The agent's codebase docs

During skill discovery, the agent writes one file here for each package it reads (`<package>.md`): what the package does, its interfaces, and what the agent found. The workspace link `$EIGEN_VECTOR_WS/agent/docs` points here (`scripts/link_agent_dir.sh`), so a new or changed doc shows as a change in git. A person reviews it and commits it.
